# Maintainers

## Primary maintainer

- [@dormitivegit](https://github.com/dormitivegit)

The primary maintainer is responsible for:

- triaging issues and pull requests, including clarifying scope and deciding
  what is ready for review;
- reviewing and merging changes based on correctness, tests, compatibility,
  security, and project fit;
- preparing releases and maintaining accurate version, changelog, and release
  notes;
- receiving private security reports, coordinating fixes, and managing
  responsible disclosure;
- setting project direction and keeping the public roadmap and documentation
  aligned with implemented behavior; and
- preserving FABLE5's behavioral contracts, deterministic outputs, and
  fail-closed boundaries, or clearly documenting and testing intentional
  contract changes.

Community members may propose changes and participate in review. Repository
and release decisions remain the responsibility of the maintainer, with
security-sensitive discussion kept in private GitHub security advisories.
