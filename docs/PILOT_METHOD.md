# Pilot method

Pilot A uses twenty materially varied low-risk task descriptions and two real
action-effect escalations. Pilot B creates only a disposable synthetic Git
repository. Pilot C1 establishes fixtures and then performs read-only guard and
integrity checks. Pilot C2 creates only sanitized target bytes inside a newly
provided disposable root and exercises no-clobber races and injected failures.

Pilot reports omit timestamps, hostnames, random identifiers, winner ordering,
and absolute roots so normalized output is deterministic.
